Every good name has a story behind it. Ours has two.

## The scientific layer

"Atto" is the smallest prefix in the International System of Units. It stands for 10⁻¹⁸ — a millionth of a billionth. It's the scale at which atoms interact, chemical reactions happen, and the detail nobody sees decides whether the whole system works.

For a software house, that reference isn't random. It's a promise: we take care of the detail that makes things work. Not the visible detail — the detail that matters. The layer where precision is the difference between software that "works" and software that *really works*.

## The pun that connects it all

In Portuguese, "atto" sounds exactly like "ato" — an act. That's where it gets interesting.

An act is action. It's the moment an idea becomes real. It's when the plan meets the field and things happen. "We turn ideas into action" isn't a slogan — it's what we do every day. From code to action. From architecture to results.

That bridge between the technical and the practical defines everything we build. Nobody wants pretty software. They want results. They want the system to run, the numbers to add up, the operation to move. That's the precision of the atto: extreme attention to technical detail, with an absolute focus on real impact.

## The name as a commitment

Choosing "Attodev" was a conscious decision. It's a permanent reminder of how we work:

- **Extreme precision** — we don't accept "good enough". Every technical decision has to be justified.
- **Resulting action** — idle code is worth nothing. The value is in what the software makes happen.
- **The detail that matters** — we don't get stuck on the cosmetic. We go straight to what decides whether the system works.
